# Alashmoon S.A.S. | Arte, Emoción y Tecnología 🌙✨

Plataforma web de comercio electrónico (e-commerce) desarrollada como proyecto formativo para el **ADSO SENA CSET** (Análisis y Desarrollo de Software). Este sitio web combina la elegancia del arte artesanal hecho a mano con la automatización digital y un diseño moderno e interactivo.

---

## 🚀 Descripción del Proyecto
Alashmoon S.A.S. es un emprendimiento enfocado en la creación y comercialización de detalles personalizados y manualidades finas. La aplicación web permite a los clientes explorar un catálogo interactivo de productos, conocer la filosofía de la empresa (Misión y Visión), visualizar reseñas verificables de clientes reales y realizar pedidos directos ya sea a través de mensajería automatizada por **WhatsApp** o mediante correo electrónico.

---

## 🛠️ Tecnologías Utilizadas
El proyecto está construido utilizando tecnologías web estándar sin dependencias de frameworks pesados, garantizando un rendimiento óptimo y una carga fluida:
* **HTML5:** Estructuración semántica del contenido de la página.
* **CSS3:** Diseño responsivo, variables CSS personalizadas, efectos visuales de cristal y animaciones avanzadas (`@keyframes`).
* **JavaScript (Vanilla):** Lógica del precargador dinámico, sistema de alternancia de múltiples números de WhatsApp corporativos y automatización de formularios de contacto.
* **FontAwesome y Google Fonts:** Iconografía moderna y tipografía optimizada (*Poppins*).

---

## 📦 Estructura de Archivos
El proyecto sigue el mandato de archivo único e integrado para despliegues rápidos:
```text
├── index.html       # Estructura principal, secciones de catálogo, nosotros, reseñas y formulario
├── style.css        # Estilos visuales, modo oscuro, efectos luminosos y diseño adaptativo (responsive)
├── script.js        # Precargador interactivo y lógica de redireccionamiento a WhatsApp y Correos
└── img/             # Carpeta de recursos gráficos (logos, fotos de productos y elementos visuales)
```

---

## 🌟 Características Principales
1. **Precargador Dinámico:** Simula la inicialización y sincronización tecnológica de la marca al cargar la página por primera vez.
2. **Catálogo Organizado:** Categorías interactivas para *Ramos de Flores Eternas (Fomi)*, *Carteleras Personalizadas* y *Cartas y Poemas a Medida*.
3. **Redireccionamiento Inteligente de WhatsApp:** Sistema rotativo de números oficiales (`+57 3160512872` / `+57 3153767043`) para equilibrar la atención al cliente de los socios fundadores.
4. **Formulario Dual:** Permite a los usuarios elegir si desean enviar el formato de pedido directamente por WhatsApp o mediante el cliente de correo institucional (`mailto`).
5. **Diseño Responsivo (*Mobile-First*):** Adaptado perfectamente para visualizarse con fluidez en teléfonos inteligentes, tablets y computadoras de escritorio.
